# Audio Effects Processor

## Overview

This project implements a browser-based audio processing system that allows users to apply and experiment with various audio effects in real time.

The application demonstrates fundamental Digital Signal Processing (DSP) concepts by modifying audio signals through interactive controls and visual feedback.

## Features

* Real-time audio playback
* Audio effect manipulation
* Interactive user controls
* Signal processing experimentation
* Audio waveform analysis

## Technologies Used

* JavaScript
* HTML
* CSS
* p5.js
* Web Audio API

## Skills Demonstrated

* Digital Signal Processing
* Audio Manipulation
* Interactive Web Development
* JavaScript Programming
* Audio Visualization

## Learning Outcomes

This project explores how digital audio signals can be modified and processed to create different listening experiences while introducing core DSP concepts used in multimedia applications.
